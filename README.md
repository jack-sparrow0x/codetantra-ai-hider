# CodeTantra SensAI Hider

A simple browser extension for **CodeTantra** that lets you toggle the visibility of the **SensAI** interface.

## ✨ Features

* 👁️ Toggle **SensAI visibility** on CodeTantra.
* 🧩 Works as a browser extension.
* 🌐 Supports Chromium-based browsers such as:

  * Google Chrome
  * Microsoft Edge
  * Brave
* 🦊 Firefox support through an `.xpi` package.
* 📦 Pre-built extension packages are included in the repository.
* 🪶 Lightweight and simple to install.

## 📥 Installation

### Chrome / Brave / Edge

1. Download the latest `codetantra-ai-hider.zip` from the repository.
2. Extract the ZIP file into a folder.
3. Open your browser's extension management page:

   * Chrome: `chrome://extensions`
   * Edge: `edge://extensions`
   * Brave: `brave://extensions`
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the folder containing the extracted extension.
7. Open CodeTantra and use the extension as needed.

### Firefox

1. Download `codetantra-ai-hider.xpi`.
2. Open Firefox.
3. Navigate to `about:addons`.
4. Click the **⚙️ gear icon**.
5. Select **Install Add-on From File...**
6. Select the downloaded `.xpi` file.
7. Confirm the installation.

## 🔧 How It Works

CodeTantra SensAI Hider is distributed as a browser extension package designed to modify the visibility of the SensAI interface on supported CodeTantra pages.

The repository also includes a small static installation website built with HTML and CSS.
