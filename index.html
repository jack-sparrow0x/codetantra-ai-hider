Installation Guide

Quickly install SensAI Hider on your browser using the release zip file.

Get the Extension

Download the latest release package containing the extension files.

Download ZIP

Chrome / Brave / Edge

  1. Download and extract the ZIP file into a folder.
  2. Open your browser and navigate to chrome://extensions.
  3. Enable Developer mode using the toggle in the top-right corner.
  4. Click Load unpacked and select the extracted folder.

Firefox

  1. Download the ZIP file (no need to extract).
  2. Open Firefox and go to about:addons.
  3. Click the gear icon (Tools for all add-ons) in the top-right corner.
  4. Select Install Add-on From File... and choose the downloaded ZIP file.
