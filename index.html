Installation Guide

Quickly install SensAI Hider on your browser using the release package.

Get the Extension

Download the latest release package tailored for your browser.

Download ZIP (Chrome / Brave / Edge) Download XPI (Firefox)

Chrome / Brave / Edge

  1. Download and extract the ZIP file into a folder.
  2. Open your browser and navigate to chrome://extensions.
  3. Enable Developer mode using the toggle in the top-right corner.
  4. Click Load unpacked and select the extracted folder.

Firefox

  1. Download the .xpi file.
  2. Open Firefox and navigate to about:addons.
  3. Click the gear icon (⚙️) in the top-right corner of the extensions page.
  4. Select Install Add-on From File... and choose the downloaded XPI file.
